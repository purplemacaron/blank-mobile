# blank mobile

폰 위에서 직접 동작하는 에이전트. 화면을 보고 탭·스와이프·입력으로 기기를 조작하고, 전화를 걸고, 앱을 실행합니다. 데스크톱 [blank](https://github.com/purplemacaron/blank)와 이름·철학만 공유하는 독립 프로젝트입니다.

- 로컬 우선: 계정 없음, 세션·키는 기기에만 저장
- 실제 프로바이더만: OpenAI 호환(LAN Ollama/LM Studio 포함), Anthropic, Gemini
- 승인 기반 안전: 기기 조작·전화는 기본적으로 사용자 확인을 거침
- 한국어 기본 UI (영어 전환 지원)

## 기능

- **모바일 유즈** — 접근성 서비스로 UI 트리·스크린샷을 읽고 탭/롱프레스/스와이프/텍스트 입력/뒤로·홈·최근 앱 실행. 셀렉터(text/resource-id/desc) 우선, 좌표 폴백.
- **전화** — 걸기(직접 발신)/다이얼러 프리필/받기/끊기/통화 상태. 발신은 번호별 승인.
- **앱 조작** — 실행/목록/설치/삭제/강제 종료. 설치·삭제는 시스템 확인 다이얼로그를 사용자가 직접 승인.
- **질문** — 에이전트가 선택지 카드로 사용자에게 질문하고 답을 기다림.
- **백그라운드 실행** — 포그라운드 서비스 + 실행 알림(중단 버튼). 승인/질문이 필요하면 알림으로 알려주고, 탭하면 앱으로 복귀.

## 설치

1. GitHub Releases에서 APK 다운로드 (또는 아래 빌드 절차로 직접 빌드).
2. APK 실행 → "출처를 알 수 없는 앱" 허용(브라우저/파일 관리자별 1회).
3. 설치 후 앱 실행.

요구사항: Android 11 (API 30) 이상.

## 초기 설정

1. **접근성 서비스** — 앱 온보딩의 안내를 따라 설정 → 접근성 → 설치된 앱 → blank mobile 활성화. 에이전트의 화면 보기·조작에 필수.
2. **배터리 최적화 예외** — 제조사별 백그라운드 제한이 있으므로 온보딩 안내에 따라 예외 설정 권장.
3. **알림 권한** — Android 13+에서 실행/승인/질문 알림에 필요.
4. **전화 권한** — 전화 걸기/받기 사용 시 런타임 권한 허용.
5. **프로바이더** — 설정에서 프로바이더/엔드포인트/모델/API 키 입력.
   - LAN 로컬 LLM: Ollama 예 `http://<PC IP>:11434/v1`, 에뮬레이터에서는 `http://10.0.2.2:11434/v1`.
   - 스크린샷 이해(vision)는 vision 지원 모델에서만 동작.

## 사용과 안전

- 기기 조작·앱 조작·전화는 기본 **승인 카드**(허용/항상 허용/거부)를 거칩니다. 전화 발신의 "항상 허용"은 번호별이며 세션 일괄 허용은 없습니다.
- 실행 중에는 알림에 **중단** 버튼이 있고, 앱 안에서도 중단할 수 있습니다.
- 시스템 설치/삭제 확인 다이얼로그는 에이전트가 누르지 않습니다. 사용자가 직접 승인합니다.
- API 키는 Android Keystore 기반 암호화 저장소에 보관되고 화면에는 마스킹된 메타만 표시됩니다.
- 스크린샷·UI 트리는 기기 로컬에만 저장되며 최근 N개만 유지합니다. 로그에 남기지 않습니다.
- 세션은 기기에 JSON으로 저장됩니다. 앱을 다시 열면 세션 목록에서 이어갈 수 있습니다(실행 재개는 해당 세션에서 새 메시지 전송).

## 한계

- **전화 끊기**: 공개 API가 없어 통화 화면의 종료 버튼을 접근성으로 클릭합니다. 다이얼러/OEM별 셀렉터 차이가 있을 수 있고, 실패 시 오류를 표시하고 수동 종료를 안내합니다.
- **강제 종료**: 루트 없이 불가 → 앱 정보 화면 경유(사용자 확인 포함).
- **OEM 백그라운드 제한**: 일부 제조사는 접근성 서비스/백그라운드 실행을 제한합니다. 배터리 최적화 예외와 접근성 재연결 안내를 따르세요.
- **Play Store 미배포**: 접근성 자동화 앱 정책 부담으로 초기에는 APK 사이드로딩만 지원합니다.
- 실기기 전화 QA는 SIM/기기 의존입니다. 에뮬레이터에서는 수신 시뮬레이션(`adb emu gsm call`)까지 검증했습니다.

## 빌드

요구사항: Android SDK (platform 36, build-tools 36.0.0), JDK 17+ (Android Studio 번들 JBR 21 권장).

```sh
# local.properties에 sdk.dir 설정 후
./gradlew assembleDebug      # APK: app/build/outputs/apk/debug/
./gradlew test               # JVM 단위 테스트 (하드웨어 불필요)
```

릴리스 서명: 저장소 루트에 `keystore.properties`(gitignore됨)를 두면 release 빌드가 자동으로 서명합니다.

```properties
storeFile=release.keystore
storePassword=...
keyAlias=...
keyPassword=...
```

키스토어와 비밀번호는 절대 커밋하지 않습니다.

```sh
./gradlew assembleRelease    # APK: app/build/outputs/apk/release/
```
