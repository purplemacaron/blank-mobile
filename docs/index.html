기기 조작·전화는 기본 승인 카드를 거칩니다.

기능

Kotlin + Jetpack Compose 네이티브. 실제 프로바이더만 지원합니다.

모바일 유즈

접근성 서비스로 UI 트리·스크린샷을 읽고 탭·롱프레스·스와이프·텍스트 입력·뒤로/홈/최근 앱을 실행합니다. 셀렉터 우선, 좌표 폴백.

전화

걸기·받기·끊기·통화 상태. 발신은 번호별 승인, 번호는 마스킹 표시.

앱 조작

실행·목록·설치·삭제·강제 종료. 설치·삭제는 시스템 확인 다이얼로그를 사용자가 직접 승인합니다.

채팅

OpenAI 호환 · Anthropic · Gemini 직접 호출, SSE 스트리밍, 스크린샷 vision. LAN Ollama/LM Studio 엔드포인트 지원.

질문 카드

에이전트가 선택지 카드로 사용자에게 질문하고 답을 기다립니다.

백그라운드 실행

포그라운드 서비스 + 실행 알림(중단 버튼). 승인·질문이 필요하면 알림으로 알려주고, 탭하면 앱으로 복귀합니다.

설치

Play Store 대신 APK 사이드로딩으로 배포합니다. Android 11 (API 30) 이상.

  1. APK 다운로드

    위 다운로드 버튼으로 최신 APK를 내려받습니다.

  2. 사이드로딩 설치

    APK 실행 → “출처를 알 수 없는 앱” 허용(브라우저/파일 관리자별 1회).

  3. 온보딩 따라 설정

    설정 → 접근성 → blank mobile 활성화 후, 프로바이더 API 키 또는 LAN 엔드포인트를 연결합니다.

안전

  • API 키는 Android Keystore 기반 암호화 저장소에 보관되고, 화면에는 마스킹된 메타만 표시됩니다.
  • 스크린샷·UI 트리는 기기 로컬에만 저장되며 로그에 남기지 않습니다.
  • 기기 조작·앱 조작·전화는 기본 승인 카드(허용/항상 허용/거부)를 거칩니다. 전화 발신의 “항상 허용”은 번호별입니다.
  • 시스템 설치/삭제 확인 다이얼로그는 에이전트가 누르지 않습니다. 사용자가 직접 승인합니다.
  • 실행 중에는 알림의 중단 버튼과 앱 안에서 언제든 중단할 수 있습니다.

알려진 한계

  • 전화 끊기는 공개 API가 없어 통화 화면의 종료 버튼을 접근성으로 클릭합니다. 다이얼러/OEM별 동작 차이가 있을 수 있습니다.
  • 강제 종료는 루트 없이 불가하여 앱 정보 화면을 경유합니다.
  • 일부 제조사는 백그라운드 실행을 제한합니다. 배터리 최적화 예외 설정을 권장합니다.
  • 실기기 전화는 에뮬레이터 수신 시뮬레이션까지 검증했습니다. 실기기 발신·수신·종료는 사용자 환경에서 추가 검증이 필요합니다.
